## 🔥 Project Overview

**This tool** is a comprehensive trainer for **WheelMates**. This trainer provides optional assistance for cooperative RC-car exploration. It focuses on vehicle movement, gadget-based traversal, puzzle navigation, and smoother progression through the professor's laboratory without adding combat systems that are not part of the game.

**Target Audience:** Players who want a more relaxed cooperative experience, easier laboratory exploration, simpler gadget traversal, or additional convenience while solving puzzles with a friend.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement options while driving the RC cars through the professor's home laboratory. Assistance is most useful when crossing narrow surfaces, navigating cluttered desks, drifting around obstacles, or attempting difficult jumps. Disable movement assistance before precision sections if you prefer the standard driving challenge.

### Tools & Inventory

WheelMates does not use a traditional inventory. Progression is based on gadgets and power-ups for the RC cars, including rope swings, magnetic wheels, and magnet grabs. Trainer options in this area should be used to support gadget access and traversal rather than conventional item management.

### World & Environment

Explore each room carefully as the house functions as a large interconnected playground. The trainer can be used to make route-finding and repeated exploration more convenient while searching for hidden paths, unlocking rooms, and investigating the professor's experiments.

### Combat & Weapons

WheelMates is a cooperative exploration and puzzle adventure with no combat gameplay. Combat-related trainer options are therefore not included.
